# CONTEMPORATY GODDESSES TAROT 🔮
Aplicación web de lectura de las cartas del tarot para descubrir tu Contemporary Goddess en el mundo Tech utilizando React.

## Descripción

La aplicación permite realizar una lectura de tarot de tres cartas:
- Pasado
- Presente
- Futuro

El usuario puede seleccionar únicamente tres cartas y posteriormente visualizar la interpretación de cada una junto con su Contemporart Goddess.

## Funcionalidades

- Visualización de cartas boca abajo.
- Selección de cartas de tarot.
- Restricción a únicamente 3 cartas.
- Asignación de pasado, presente y futuro.
- Vista final de la lectura.
- Modal con información detallada de cada carta.
- Diseño responsive.

## Instalación

Clonar el repositorio:

```bash
git clone https://github.com/tarot-team2/tarot-project.git
```

Entrar en la carpeta:

```bash
cd tarot-project
```

Instalar dependencias:

```bash
npm install
```

Ejecutar el proyecto:

```bash
npm run dev
```
